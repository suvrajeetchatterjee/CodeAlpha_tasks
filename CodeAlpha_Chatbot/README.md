# Basic Chatbot 🤖

A simple rule-based chatbot developed using Python as part of the **CodeAlpha Python Programming Internship - Task 4**.

## 📌 Description

This project is a basic text-based chatbot that interacts with the user through the command line.

The chatbot uses predefined rules and keyword matching to recognize common inputs and provide appropriate responses.

It can respond to:

- Greetings such as `hello`, `hi`, and `hey`
- Questions such as `how are you`
- Questions about its name
- Thank-you messages
- Help requests
- Questions about what it can do
- Farewell messages such as `bye`, `goodbye`, and `see you`

For unrecognized inputs, the chatbot provides a randomly selected fallback response.

## ✨ Features

- Simple command-line conversation
- Rule-based responses
- Keyword matching
- Case-insensitive user input
- Multiple predefined responses
- Random fallback responses
- Continuous conversation using a loop
- `bye`, `goodbye`, or `see you` can be used to exit

## 🛠️ Technologies Used

- Python
- `if-elif-else` statements
- Functions
- Loops
- User input/output
- `random` module
