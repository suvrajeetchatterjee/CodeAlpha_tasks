# Hangman Game 🎮

A simple text-based Hangman game developed using Python as part of the **CodeAlpha Python Programming Internship - Task 1**.

## 📌 Description

This project is a command-line Hangman game where the player attempts to guess a randomly selected word one letter at a time.

The game provides a limited number of incorrect guesses and displays the player's progress as letters are correctly guessed.

## ✨ Features

- Random word selection
- Letter-by-letter guessing
- Tracks incorrect guesses
- Prevents duplicate guesses
- Displays word progress
- Input validation
- Win and game-over conditions
- Option to play again

## 🛠️ Technologies Used

- Python
- `random` module
- Functions
- Loops
- Conditional statements
- User input/output
