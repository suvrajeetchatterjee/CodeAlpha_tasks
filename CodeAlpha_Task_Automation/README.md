# Task Automation with Python

CodeAlpha Python Programming Internship - Task 3

## Description

This project contains three simple Python automation tasks:

1. Move all `.jpg` files from one folder to another.
2. Extract email addresses from a `.txt` file.
3. Scrape the title of a webpage and save it to a file.

## Technologies Used

- Python
- os
- shutil
- re
- requests
- File handling
