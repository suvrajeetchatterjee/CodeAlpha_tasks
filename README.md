# CodeAlpha Python Programming Internship 🚀

This repository contains the Python projects completed as part of the **CodeAlpha Python Programming Internship**.

The projects demonstrate fundamental Python programming concepts including functions, loops, conditional statements, user input/output, file handling, regular expressions, and basic automation.

## 📂 Projects

### 🎮 Task 1 - Hangman Game

A simple text-based Hangman game where the player guesses a randomly selected word one letter at a time.

**Key Features:**
- Random word selection
- Letter-by-letter guessing
- Incorrect guess tracking
- Input validation
- Duplicate guess detection
- Win and game-over conditions
- Play-again functionality

📁 **Folder:** `CodeAlpha_Hangman`

---

### ⚙️ Task 3 - Task Automation

A collection of Python automation scripts designed to perform simple real-life tasks.

**Key Features:**
- Move `.jpg` files between folders
- Extract email addresses from `.txt` files
- Scrape the title of a webpage
- Interactive menu for selecting tasks

📁 **Folder:** `CodeAlpha_Task_Automation`

---

### 🤖 Task 4 - Basic Chatbot

A simple rule-based chatbot that responds to predefined user inputs using keyword matching.

**Key Features:**
- Responds to greetings
- Answers simple questions
- Responds to help requests
- Handles thank-you messages
- Provides random fallback responses
- Supports continuous conversation
- Exit using `bye`, `goodbye`, or `see you`

📁 **Folder:** `CodeAlpha_Chatbot`
